# Lucky Block Addon

Break Lucky Blocks and discover random rewards!

## Features

- **Lucky Block:** Break it to get random Minecraft items.
- **Addon Compatibility:** Supports items and blocks from other addons, allowing their custom content to appear in Lucky Block rewards.
- **Loot Bags:** Open loot bags to receive different types of rewards.

## Loot Bags

### Basic Loot Bag
- Can be crafted.
- Drops only vanilla Minecraft items.

### Ultimate Loot Bag
- Cannot be crafted.
- Can be found in loot chests, such as village chests.
- Can drop both Minecraft items and items from other addons.

## Compatibility
Designed to support custom items and blocks from other addons.

Have fun breaking Lucky Blocks and discovering amazing rewards!
